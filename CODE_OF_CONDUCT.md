# Code of Conduct

This repository is a working project. Keep the discussion focused on the work
and the evidence.

## Expected behavior

- Be respectful.
- Critique the change, not the person.
- Keep feedback specific and actionable.
- Do not harass, threaten, discriminate, or spam.
- Do not use pull requests or issues to waste other people’s time.

## Unacceptable behavior

- Personal attacks.
- Harassment or intimidation.
- Discriminatory language or behavior.
- Deliberate disruption of discussion or review.
- Publishing private information without permission.

## Enforcement

Maintainers may remove content, close threads, or restrict participation when
behavior makes the repository harder to work in.

If you need to report a problem, use a private maintainer channel or a private
GitHub security/advisory path rather than a public issue.
