# Plain-language report pass (bundled)

Turn raw findings into a short report.

Steps:

1. Read plain-language-principles.md
2. Read output-formats.md
3. Draft short complete sentences
4. For Brazilian Portuguese, follow glossary-usage.md
5. Run self-review sweeps
6. Return in chat only unless the user asks to save

Hard rules: no abbreviations, no acronyms, no decorative symbols, name rules in plain words, keep file paths, each finding has what is wrong / which rule / where / what to change.
