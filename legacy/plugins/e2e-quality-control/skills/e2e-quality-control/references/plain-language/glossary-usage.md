# Glossary usage (bundled)

Use this when the report language is Brazilian Portuguese, or when English
drafts need a consistent technical term.

## Isolation note for this skill

The quality check itself may only read the packaged quality rules and the
selected target files. The plain-language rewrite may also read this folder.
If a project glossary file is already known to the host session, you may use it
for term lookup. Do not open other project files while rewriting the report.

## Lookup order

1. Exact key in the glossary
2. Listed aliases
3. Substring scan per the glossary schema

## Brazilian Portuguese

Replace awkward borrowed English with the glossary Portuguese value when one
exists. Keep file paths and identifiers in their original form, and add a short
plain explanation in the same sentence.

## English

Prefer the glossary English key when a term was written in a confusing way.

## Missing terms

If there is no glossary entry, do not invent jargon. Use a plain paraphrase.
You may note unresolved terms only in private notes, not in the report.
